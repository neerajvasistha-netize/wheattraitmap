# Biotroph (rusts, powdery mildew and other biotrophic diseases) papers for WheatRLA

Screening and download tracking for the biotrophic-disease module of the atlas.

| File | What it is |
|---|---|
| `00_source_WheatRLA_biotroph_remaining_papers.bib` | Starting list: 2,474 candidate papers |
| `01_kept_mapping_papers.bib` | 1,587 papers kept for the atlas: gene/QTL mapping, GWAS (MTA/QTN), fine mapping, candidate genes, gene cloning, gene location, alien transfers (wheat only) |
| `02_removed_not_mapping_or_not_wheat.bib` | 887 removed: virulence/race surveys, gene postulation and marker screening, expression/functional studies, MAS/breeding, reviews, errata; plus 46 non-wheat papers (other crops, barley genes, rye-only, triticale-only) |
| `03_screening_decisions.csv` | Keep/remove decision and reason for every paper |
| `04_not_downloaded.bib` | Kept papers still without a PDF (933 on 19 Nov 2026) |
| `05_download_tracker_links.xlsx` | DOI and Google Scholar links; sheet "Not downloaded" plus "All papers" with Downloaded (Y/N) |

Download status is checked against the owner's Zotero library and Zotero exports (PDFs themselves are not stored here).
Updated: 19 Nov 2026.
